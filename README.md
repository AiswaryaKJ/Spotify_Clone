# 🎵 My Spotify Clone

A sleek and responsive **Spotify clone** built using **HTML**, **CSS**, and **JavaScript**. It replicates the core design and features of Spotify, including a music player, custom playlist UI, and basic media controls.

## 💻 Tech Stack

- **HTML5** – Markup and structure
- **CSS3** – Styling and layout (Flexbox, Grid, Transitions)
- **JavaScript (ES6)** – Interactivity, DOM manipulation, and audio control

## ⚙️ Features

- Play/Pause audio playback
- Dynamic progress bar
- Playlist interface with song list
- Responsive design for desktop and mobile
